# ForgeGrid overview

ForgeGrid develops 3D-printable, modular collector-workstation components from
a shared OpenSCAD library. The project validates a connector before applying it
to card sorters, deck docks, dice trays, and related modules.

The first engineering question is fit: which clearance performs reliably on
the target printer and material? FG-CONN-100 answers that question before
adding magnets, preload tabs, or product geometry.
