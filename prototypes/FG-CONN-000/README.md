# FG-CONN-000 Datum Verification

This is a quick geometry check before printing FG-CONN-200.

1. Render with F6.
2. Export STL.
3. Open the STL in your slicer.
4. Use the slicer's "place on bed" or layer-preview tools to confirm that all
   four coupons begin at Z=0.
5. Verify there are no floating islands on the first layer.
6. Print without supports.

If all four coupons sit flat and print cleanly, continue to FG-CONN-200.
