# FG-CONN-200 Engagement Length Test

## Before printing

Print or inspect `../FG-CONN-000/FG-CONN-000.scad` first.

## Variants

- ENG-010
- ENG-015
- ENG-020
- ENG-025
- ENG-030

Choose the shortest engagement that provides smooth operation, negligible
play, and satisfactory twist resistance.
